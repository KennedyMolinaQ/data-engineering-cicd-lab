1. **Control de versiones** — branches, Pull Requests, Git Flow.
2. **Desarrollo** — Python, PySpark, organización del código.
3. **Calidad** — linter, formateo, testing.
4. **CI** — GitHub Actions: deps, lint, format, tests, validaciones.
5. **CD** — validar bundle, desplegar a Databricks, ejecutar Job.
6. **Documentación** — clara para cada módulo.
